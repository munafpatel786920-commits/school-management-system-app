# **App Name**: VidyaVerse

## Core Features:

- User Authentication and Roles: Firebase Authentication to manage different user roles: Admin, Teacher, Student, and Accountant with role-based access control.
- Student Management: Add, edit, and delete student profiles with detailed information including photo, personal details, class, and admission number.
- Teacher Management: Manage teacher profiles, subject allocation, and class teacher assignments.
- Attendance System: Daily attendance tracking for students and teachers with monthly and yearly report generation.
- Fees Management: Manage fee structures, generate receipts with school details, student details, amount in Indian Rupees (₹), and track fee status (Paid/Pending).
- Document Generation: AI tool which can Generate professional Indian school-style documents, including Fee Receipts, Bonafide Certificates, Leaving Certificates (LC), Transfer Certificates, Marksheets, and Attendance Reports.
- Print and PDF Support: Generate A4 size documents with portrait and landscape support, ensuring the preview matches the print output. All documents will be rendered without cuts.

## Style Guidelines:

- Primary color: Soft sky blue (#87CEEB) to evoke trust and tranquility in an educational environment.
- Background color: Very light grey (#F0F0F0), offering a clean and uncluttered backdrop.
- Accent color: Warm gold (#FFD700) for highlighting important actions and information.
- Headline font: 'Poppins' sans-serif font for titles; Body font: 'PT Sans' for body text. The former lends a contemporary, precise feel to titles, and the latter combines modernity with readability.
- Simple, clear icons for navigation and actions.
- Clean and structured layout with sidebar navigation. Responsive design for both mobile and desktop.
- Subtle transitions and animations for a smooth user experience.
